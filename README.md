# 8NAP public assets

Public poster images used by the 8NAP Discord bot. This repository contains image assets only.

## Image URLs

Images are served from:

`https://raw.githubusercontent.com/0xfnkl/8nap-assets/main/media-posters/<lowercase-contract-address>/<filename>`

Keep existing paths stable so Discord embeds continue to load. To add a poster, place the image under `media-posters/<lowercase-contract-address>/` and update the bot configuration separately.
